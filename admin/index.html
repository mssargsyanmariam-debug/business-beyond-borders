Sign in

Paste your GitHub access key once. It stays in this browser only, and is never sent anywhere except GitHub.

How to get your key (once, about 2 minutes)

  1. Open github.com/settings/personal-access-tokens/new while signed in to GitHub.
  2. Token name: anything, for example "Website admin".
  3. Expiration: pick 1 year (you'll create a new one after that).
  4. Repository access: choose "Only select repositories" → business-beyond-borders.
  5. Permissions → Repository permissions → Contents: set to Read and write.
  6. Click Generate token, copy it, and paste it above.

The key only allows changes to this one website. If you ever lose your laptop, delete the key on GitHub and it stops working.
