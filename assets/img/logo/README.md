# Business Beyond Borders logo

Matched to the business card: navy `#0C162E`, red `#D61E25`, white.
The map is a real coastline outline (Natural Earth, public domain), flat and
cropped above Antarctica, exactly as on the card.
Type: Archivo (free, Google Fonts) — Black for the B's, ExtraBold for the words.

## Which file to use

| Where | File |
| --- | --- |
| WhatsApp channel, LinkedIn, Instagram profile picture | `bbb-avatar.png` |
| Slides, social posts, anything on a dark background | `bbb-logo.png` |
| Documents, letters, invoices, anything on white | `bbb-logo-light.png` |
| Website header, email signature, LinkedIn cover | `bbb-wordmark.png` |
| The same on white | `bbb-wordmark-light.png` |
| Printing, large banners, roll-ups, merchandise | the `.svg` files |
| When a tool will not take SVG but needs it big | the `@2000` and `@2x` files |

## About the files

- **`.svg`** — vector. It stays sharp at any size, from a business card to a
  building. The lettering is already turned into outlines, so it looks right on
  any computer even without the font installed. Give these to a printer.
- **`.png`** — ordinary images. The plain ones are 1000px, the `@2000` and `@2x`
  ones are double that for print and large screens.
- **`-light`** files have a see-through background for white pages; the others
  carry the navy background with them.
